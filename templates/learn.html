1.1. Ma'lumotlarni ekranga chiqarish (print)

Python tilida ekranga matn yoki o'zgaruvchi qiymatini chop etish uchun print() o'rnatilgan funksiyasidan foydalaniladi.

python_intro.py Python 3 
# Salom Dunyo dasturi
print("Assalomu alaykum, AlgoPlay!")

# O'zgaruvchilar e'lon qilish
ism = "Kamola"           # Matn (str)
yosh = 20               # Butun son (int)
narx = 19.99            # Haqiqiy son (float)
talabami = True         # Mantiqiy qiymat (bool)

print(ism, "yoshi:", yosh)
Assalomu alaykum, AlgoPlay!  |  Kamola yoshi: 20

Shart Operatori (if, elif, else)

Mantiqiy Tanlovlar
15 XP

Dastur ma'lum bir shart bajarilgandagina biror amalni bajarishi uchun if-elif-else tuzilmasidan foydalaniladi.

conditions.py Python 3 
ball = 85

if ball >= 90:
    print("A'lo baho! Siz dasturlash dahosisiz 🏆")
elif ball >= 70:
    print("Yaxshi natija! Mashq qilishda davom eting 🚀")
else:
    print("Yana bir bor urinib ko'ring! 💪")
Yaxshi natija! Mashq qilishda davom eting 🚀
Diqqat (Sintaksis qoidasi): if va else qatorlari oxirida doimo ikki nuqta (:) qo'yilishi shart, aks holda dasturda SyntaxError yuz beradi! Taqqoslash uchun esa ikki barobar (==) belgisi ishlatiladi. Yagona = belgisi faqat qiymat o'zlashtirish uchun.
Taqqoslash va shartlar bo'yicha mashq Shartdagi Xatoni Qidirish

Sikllar (for va while)

Takroriy Harakatlar
20 XP

Bir xil amalni ko'p marta takrorlash uchun sikllar ishlatiladi.

  • for sikli: Ro'yxat yoki range() diapazonidagi elementlarni birma-bir aylanib chiqish uchun qulay.
  • while sikli: Shart toki True (to'g'ri) bo'lib turgunicha uzluksiz takrorlanadi.
loops.py Python 3 
# 1 dan 5 gacha sonlarni chiqarish (range(1, 6) 1 dan 5 gacha ishlaydi, 6 kirmaydi)
for son in range(1, 6):
    print("Son:", son)

# While sikli
urinish = 3
while urinish > 0:
    print("Qolgan imkoniyat:", urinish)
    urinish -= 1
Son: 1 ... Son: 5  |  Qolgan imkoniyat: 3, 2, 1

Funksiyalar (Functions)

Kodni Qayta Ishlatish
20 XP

Funksiya — ma'lum bir vazifani bajaruvchi mustaqil kod blokidir. U bir marta yoziladi va dastur davomida istalgancha chaqirib ishlatiladi.

Funksiya def kalit so'zi bilan e'lon qilinadi va natijani qaytarish uchun return buyrug'i ishlatiladi.

functions.py Python 3 
def ikkita_son_yigindisi(a, b):
    natija = a + b
    return natija

# Funksiyani chaqirish
javob = ikkita_son_yigindisi(15, 25)
print("Yig'indi:", javob)  # Natija: 40
Yig'indi: 40

Ma'lumotlar Tuzilmasi (Data Structures)

List, Tuple, Dict, Stack & Queue
25 XP

Ma'lumotlar tuzilmalari — kompyuter xotirasida axborotlarni tartibli va qulay saqlash usullaridir.

Ro'yxat (List)

Elementlar tartiblangan, o'zgaruvchan (mutable). Indekslar 0 dan boshlanadi! Uzunligini bilish uchun len() funksiyasi ishlatiladi.

Kortej (Tuple)

Yaratilgach uning elementlarini o'zgartirib bo'lmaydi (immutable). Oddiy qavslar () bilan yoziladi.

Stek (Stack)

LIFO (Last In First Out) tamoyili: oxirgi kirgan element birinchi bo'lib olinadi. Likopchalar taxlamiga o'xshaydi.

Navbat (Queue)

FIFO (First In First Out) tamoyili: birinchi navbatga turgan odam birinchi xizmat oladi va chiqadi.

Test Savoli: LIFO (Oxirgi kirgan - birinchi chiqadi) tamoyilida qaysi tuzilma ishlaydi? Javob: Stek (Stack)!

Algoritmlar Asoslari & Big-O Murakkablik

Tezlik va Samaradorlik
30 XP

Algoritm — muayyan vazifani bosqichma-bosqich hal qilish uchun tuzilgan aniq ko'rsatmalar ketma-ketligi.

6.1. Ikkilik Qidiruv (Binary Search)

Saralangan (o'sish tartibidagi) ro'yxatdan element qidirishning eng samarali usuli. Har bir qadamda qidiruv sohasini yarmiga qisqartiradi. Uning vaqt murakkabligi: O(log n) ga teng!

6.2. Saralash Algoritmlari

  • Bubble Sort (Pufaksimon): Qo'shni elementlarni solishtirib o'rnini almashtiradi. Murakkabligi: O(n^2).
  • Merge Sort (Birlashtirish): "Bo'lib tashla va hukmronlik qil" (Divide & Conquer) usulidan foydalanadi. Murakkabligi: O(n log n).
Esda saqlang: Binary Search murakkabligi O(log n), Merge Sort esa bo'lib tashla usulida ishlaydi!

Dasturdagi Xatoliklar (Bugs) va Ularni Tuzatish

Bug Hunting & Debugging
25 XP

Dasturchining 70% vaqti xatolarni qidirish va to'g'rilash (debugging) bilan o'tadi. Eng keng tarqalgan xatolar:

  • SyntaxError: Imlo xatosi (ikki nuqta : qolib ketishi, yopilmagan qavslar).
  • IndexError: Mavjud bo'lmagan indeksga murojaat qilish (masalan, 3 ta elementli ro'yxatdan 3-indeksni so'rash, chunki indekslar 0, 1, 2 bo'ladi).
  • TypeError: Mos kelmaydigan turlarni biriktirish (masalan, son bilan matnni to'g'ridan to'g'ri qo'shish: 5 + "olma").
